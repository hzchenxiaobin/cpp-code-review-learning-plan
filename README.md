# C++ 代码检视 · 按天学习计划（120 天 / 24 周）

> 配套总路线：阶段 0 语言基础 → 阶段 1 检视通识 → 阶段 2 C++ 专项 → 阶段 3 工具链 → 阶段 4 实战进阶。
> 每周 5 个学习日 + 1 个可选周末块；每天 60–90 分钟。
>
> 📚 **每日图文教程**：本计划正被逐日展开为可独立学习的教程（讲解 + 实测代码 + 图解 + 验收清单），见 [tutorials/](tutorials/README.md)。

---

## 一、使用说明

- **每日三段式节奏**：`输入 30 min`（读书 / 文档 / 高手评论）→ `练习 40 min`（写代码或审 diff）→ `记录 10–20 min`（更新个人 checklist、写 review 日记）。
- **每周第 5 天**是综合练习 / 复盘日，当天太忙可以挪到周末，但不要跳过。
- **打卡方式**：完成当天"产出"列即打 ✅；每周日检查完成率，**低于 60% 就给下周减量**，可持续比强度重要。
- **如何调整**：
  - 某天内容已熟悉 → 直接做当日练习，通过即跳过；
  - 全职学习 → 每天合并 2 天内容，总周期压缩到约 12 周；
  - 每周只有 3 天时间 → 保留每周 Day 1–3 + Day 5，周期不变、深度略降。
- **两个常备文件**（Day 1 建好）：
  - `my-review-checklist.md`：个人检视清单，从 v0.1 一路迭代到 v3.0；
  - `review-diary.md`：review 日记，记录每次审了什么、漏了什么、沟通效果。

## 五、附录

### A. checklist 种子条目（示例，从 Day 2 开始持续扩充）

1. 每个裸 `new` 的所有权去向是否明确？是否有异常 / 提前 return 路径泄漏？
2. `shared_ptr` 之间是否可能形成环？回调 / 观察者是否长期持有强引用？
3. `string_view` / `span` 参数是否被存为成员或在异步任务中使用？
4. lambda 按引用捕获的变量，生命周期是否覆盖调用点？
5. `v[i - 1]`、`v.size() - 1` 等表达式在空容器 / 无符号下溢时是否安全？
6. 循环中 `push_back` / `erase` 后，之前保存的迭代器 / 指针 / 引用是否仍有效？
7. 多线程访问的共享数据，保护范围是否完整覆盖所有读写路径？
8. 被移动的对象后续是否又被读取？
9. 函数返回值：返回局部变量引用 / 指针 / `string_view` 了吗？
10. 热路径上是否有可避免的拷贝（传值大对象、返回时多余 `std::move`）？
